# Aborted, kept because it is what happened

Started with `--trials 200` at 48000 steady-state particles. A trial costs about a minute at
that count, so the run would have taken well over an hour of a core for a what-if; it was
stopped after a few trials, before `summary.yaml` or `kidnap_trials.csv` were written. The
lines of `run.log` are the trials that finished. The same configuration was rerun with fewer
trials as `2026-10-10-kidnap-model-whatif-48000`.
